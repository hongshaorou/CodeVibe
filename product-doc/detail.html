Svelte 5 的符文 (Runes) 真的比 React Hooks 更好吗？

ReactGuru

发布于 2025-09-08

最近Svelte 5引入了符文（Runes）作为新的响应式API，在社区引发了热烈讨论。很多人认为它解决了React Hooks的心智模型难题，比如闭包陷阱和复杂的依赖数组。

“任何足够先进的技术都与魔法无异。” —— 亚瑟·克拉克。Svelte的编译时魔法似乎正在验证这一点。

让我们看看一段Hooks代码的常见问题：

function Counter() {
  const [count, setCount] = useState(0);
  useEffect(() => {
    const interval = setInterval(() => {
      console.log(count); // 这里会一直打印 0
    }, 1000);
    return () => clearInterval(interval);
  }, []); // 依赖项数组为空
}

当然，Hooks也有其优势：

  • 庞大的生态系统和社区支持。
  • 纯JavaScript，无需特定的编译器。
  • 灵活性高，可以组合出复杂的逻辑。

那么，大家怎么看？你更喜欢哪种范式？
