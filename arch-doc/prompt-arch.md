# 此文档是记录 CodeVibe 项目的架构设计的提示词

1、帮我阅读 product-doc 目录下的所有需求文档及产品原型，同时阅读 arch-doc 架构设计目录中的文档
2、代码生成需要符合以下三个原则
 - KISS原则（Keep It Simple, Stupid，保持简单直白）
 - SOLID原则（Single Responsibility Principle，单一职责）
 - DRY（Don't Repeat Yourself，不要重复自己）
3、不使用微服务 和 Redis
4、在 arch-doc 目录下生成架构设计，并写入 CodeVibe_Arch_v01.md 文件中
