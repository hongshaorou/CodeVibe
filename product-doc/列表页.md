### 一、 VibeCoding 列表页功能

VibeCoding 的社区首页（列表页）是一个以内容为核心、移动端优先、交互体验流畅的信息流页面。它融合了沉浸式浏览、内容发现和核心社区操作，整体设计遵循简洁、高效的原则。

#### **1. 整体布局与风格 (Layout & Style)**

* **环境模拟**: 页面核心内容被包裹在一个 `420x850px` 的手机模型 (`.mobile-shell`) 中，提供了真实的 App 预览效果。
* **三段式结构**:
    * **顶部状态栏 (`.status-bar`)**: 固定在最上方，白色背景，带有下边框，左对齐显示社区名称 "VibeCoding社区"。
    * **内容区 (`.feed-container`)**: 占据绝大部分空间，是所有内容卡片滚动的区域。
    * **底部导航栏 (`<footer>`)**: 固定在最下方，白色背景，带有上边框，提供 App 级别的核心导航功能。
* **核心交互 - 滚动吸附**: 内容区采用了 CSS `scroll-snap` 技术，用户上下滑动时，页面会**自动吸附**到每张卡片的顶部，实现“一划一张”的沉浸式全屏浏览体验。

#### **2. 交互式顶部栏 (Interactive Header)**

这是一个整合了搜索与筛选功能的多功能区域，位于状态栏下方。

* **可展开的搜索功能**:
    * **默认状态**: 界面极其简洁，仅在标签栏最左侧显示一个**搜索图标**。
    * **交互动画**: 点击该图标，一个完整的搜索框会从其下方**平滑向下展开**，并将下方内容推开。再次点击则平滑收起。
    * **用户体验**: 搜索框展开后，光标会**自动聚焦**，用户可立即输入，无需额外点击。
    * **实时搜索**: 在输入框中输入关键词，下方的卡片列表会**即时筛选**出标题或内容中包含该关键词的帖子。
* **动态标签筛选**:
    * **水平滚动**: 标签栏与搜索图标在同一行，当标签过多时可**水平滑动**浏览。
    * **动态生成**: 页面加载时，JavaScript 会自动遍历所有帖子数据，提取出所有 `tags`，并统计每个标签下的帖子数量，动态生成筛选按钮（如 `React (5)`）。
    * **筛选逻辑**: 点击任一标签，内容区会立刻只显示包含该标签的帖子。被选中的标签会以**品牌蓝色高亮**显示。提供一个“全部”按钮用于清除筛选。

#### **3. 卡片设计 (Card Design)**

卡片是信息的核心载体，设计上兼顾了信息密度与视觉吸引力。

* **统一样式**: 白色背景、大圆角 (`rounded-xl`)、柔和阴影 (`shadow-md`)。
* **自适应高度**: 卡片高度由内容决定，但设置了 `max-height: 75vh` 的最大高度，以确保下一张卡片能露出小部分，引导用户继续浏览。
* **丰富的卡片内部结构**:
    * **作者信息**: 顶部包含作者圆形头像和昵称。
    * **标题**: 醒目的加粗大标题。
    * **多媒体内容区**: 核心区域，能根据帖子类型自适应展示：
        * **图片 (`image`)**: 展示一张高占比的清晰大图。
        * **视频 (`video`)**: 直接内嵌视频播放器，用户可在信息流中直接播放。
        * **文本 (`text`)**: 展示摘要内容，若文字过长，该区域可**独立滚动**，不影响整个卡片的吸附。
    * **信息补充区**:
        * **标签**: 以胶囊样式展示帖子的分类标签。
        * **互动数据**: 使用图标清晰展示**点赞数**和**评论数**。
        * **操作按钮**: 提供“收藏”和“分享”的快捷操作图标。
    * **评论预览**: 卡片最底部会展示 **2-3 条**最热门的评论，并提供“查看全部 N 条评论...”的链接，引导用户进入详情页。

#### **4. 技术实现 (JavaScript Logic)**

* **数据驱动**: 整个列表由一个 `mockData` 数组在前端动态渲染，实现了视图与数据的分离。
* **模块化函数**: 逻辑被拆分为 `renderFeed` (渲染卡片)、`renderTagFilters` (渲染标签) 和 `filterAndRenderFeed` (执行筛选并调用渲染) 等多个函数，代码结构清晰。
* **复合筛选**: 筛选逻辑可以同时处理**标签筛选**和**关键词搜索**两个维度，并实时更新视图。

### 二、 VibeCoding 列表页 - 终极版提示词

**角色：** 你是一位名为 CodeVibe 的 AI 产品原型设计师，精通前端技术和交互设计，擅长构建数据驱动的移动端界面。

**任务：** 请为 VibeCoding 技术社区生成一个功能完整的**社区首页/列表页**高保真、单文件、可交互的 HTML 原型。

**总体要求：**
* **技术栈**: 纯 HTML、Tailwind CSS (CDN)、原生 JavaScript。
* **环境**: 在 `420x850px` 的 `.mobile-shell` 容器内模拟手机 App 效果。
* **代码质量**: 代码必须完整、可直接运行，所有交互逻辑（尤其是筛选和动画）必须完整实现。

### 详细功能点：

#### **1. 页面布局与核心交互**
* **顶部状态栏**: 固定，左对齐显示标题“VibeCoding社区”。
* **内容滚动区 (`.feed-container`)**:
    * 必须使用 **CSS Scroll Snap** (`scroll-snap-type: y mandatory;`) 实现“一划一张”的沉浸式滚动吸附体验。
    * 当没有筛选结果时，需显示“没有找到相关内容”的提示。
* **底部导航栏**: 固定，包含五个图标（首页、精华、发布、收藏、我的）。“首页”图标和文字为**品牌蓝色**激活状态。中间的“发布”按钮为一个更大的、悬浮的蓝色圆形 `+` 按钮。

#### **2. 交互式顶部栏 (搜索与筛选)**
* 在状态栏下方创建一个统一的、白色背景的顶部栏，包含以下功能：
* **可展开的搜索框**:
    * 默认只在最左侧显示一个**搜索SVG图标按钮**。
    * 点击此图标，一个完整的圆角搜索框从下方**平滑向下展开**（通过 `max-height` 和 `opacity` 过渡），同时输入框**自动获得焦点**。
    * 再次点击图标，搜索框平滑收起。
* **水平滚动标签栏**:
    * 与搜索图标在同一行，并占据右侧所有剩余空间。
    * 此区域需能**水平溢出滚动**（并隐藏滚动条）。
    * 使用 JavaScript 动态生成所有标签按钮，并显示每个标签对应的帖子数量。
    * 点击标签可筛选内容，被选中的标签需有**蓝色高亮**的激活样式。

#### **3. 卡片设计 (`.feed-card`)**
* **样式**: 白色背景、`rounded-xl` 圆角、`shadow-md` 阴影。
* **高度**: 最大高度 `75vh`，内容超长时内部可滚动。
* **内容适配**:
    * **视频帖子**: 内嵌 `<video>` 标签，带播放控件。
    * **图片帖子**: 显示 `<img />` 大图。
    * **纯文本帖子**: 显示 `<p>` 段落，且内容区可独立滚动。
* **卡片结构**:
    1.  **顶部**: 作者头像和昵称。
    2.  **中部**: 加粗的标题，下方是多媒体内容区。
    3.  **底部**:
        * 一行胶囊样式的**技术标签**。
        * 一行互动数据，包含带图标的**点赞/评论数**，以及**收藏/分享**图标按钮。
        * 一个浅灰色背景的区域，用于**预览 2 条评论**，并提供“查看全部 N 条评论...”的链接。

#### **4. JavaScript 动态逻辑**
* 在 `<script>` 标签内创建一个 `mockData` 数组（至少包含 5 条帖子），数据必须包含 `type` ('image'/'video'/'text'), `title`, `content`, `tags` (数组), `likes`, `commentsCount`, `comments` (对象数组) 等字段。
* **动态渲染**: 页面加载时，遍历 `mockData` 动态生成所有卡片和标签筛选器。
* **实时筛选**:
    * 为搜索框添加 `input` 事件监听，根据用户输入实时筛选 `mockData` 并重新渲染卡片列表。
    * 为所有标签按钮添加 `click` 事件监听，根据所选标签筛选 `mockData` 并重新渲染。
    * 筛选逻辑必须能**同时处理**搜索关键词和标签的组合条件。
* **动画逻辑**: 编写控制搜索框展开/收起的 JavaScript 和 CSS 动画代码。
