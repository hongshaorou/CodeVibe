# CodeVibe 项目文档

## 📋 项目概述

**CodeVibe** (VibeCoding) 是一个现代化的技术问答与分享社区平台，旨在为开发者提供高质量、高效率、沉浸式的技术交流和知识分享环境。项目主要以微信小程序形态呈现，核心功能包括内容发布、浏览、互动（评论、点赞、收藏、分享）等。

### 🎯 核心目标
- **极致的用户体验**: 通过卡片式设计、平滑的动效和沉浸式浏览，提供移动端优先的极致体验
- **高质量内容**: 鼓励深度技术内容的创作与分享，支持 Markdown 格式和富文本
- **高效的互动**: 提供便捷、强大的评论与回复系统，促进社区成员间的有效沟通

### 🎨 设计语言
- **整体风格**: 遵循 Google 的卡片式设计风格（Card-based Design），界面简洁、层级清晰
- **主色调**: 以品牌蓝 (`#4285F4`) 和白色为主色调，营造专业、清爽的技术社区氛围
- **核心原型**: 所有页面的设计均基于一个 `420x850px` 的手机模型进行，确保移动端体验的一致性

## 🔧 技术栈

### 后端技术
- **Python 3.13.3** - 主要编程语言
- **FastAPI** - 高性能 Web 框架
- **SQLAlchemy** - ORM 数据库操作
- **SQLite** - 数据库（可扩展为 PostgreSQL/MySQL）
- **JWT** - 用户认证
- **Pydantic** - 数据验证

### 前端技术
- **Vue.js 3** - 渐进式 JavaScript 框架
- **Vue Router** - 前端路由
- **Axios** - HTTP 客户端
- **Tailwind CSS** - 实用优先的 CSS 框架

### 微信小程序
- **原生小程序开发** - 微信小程序框架

### 原型开发
- **HTML + Tailwind CSS (CDN)** - 快速原型构建
- **原生 JavaScript** - 交互逻辑实现

## ✨ 核心功能模块

### 🏠 社区首页（列表页）
- 卡片式信息流设计
- CSS Scroll Snap 技术实现"一划一张"滚动体验
- 支持视频、图片、文本多媒体内容展示
- 评论预览和快速互动功能

### 📄 内容详情页
- 完整的 Markdown 内容渲染
- 代码高亮显示（highlight.js + atom-one-dark 主题）
- 强大的评论/回复系统
- 底部滑出式编辑面板，支持全屏编辑

### ✍️ 发布内容
- 沉浸式内容创作环境
- Vditor Markdown 编辑器集成
- 支持图片上传和文件导入
- 标签系统和内容分类

### ⭐ 收藏管理
- 个人收藏内容集中管理
- 搜索和标签筛选功能
- 与列表页一致的浏览体验

### 👤 个人中心
- 双视图状态管理（登录/未登录）
- 微信一键登录/注册
- 个人内容管理入口

## 📖 文档使用指南

### 🚀 快速开始
1. **了解项目**: 首先阅读 `CodeVibe需求 v2.md` 获取项目全貌
2. **技术概览**: 查看 `vibecoding_club.md` 了解技术栈选择
3. **功能体验**: 打开对应的 HTML 原型文件体验各页面功能
4. **深入理解**: 阅读各功能模块的详细说明文档

### 📋 开发流程建议
1. **需求分析**: 基于需求文档理解业务逻辑
2. **原型参考**: 使用 HTML 原型作为 UI/UX 参考
3. **功能实现**: 按照功能说明文档进行开发
4. **测试验证**: 对照原型验证功能完整性

### 🔄 文档维护
- 功能变更时及时更新对应的说明文档
- 新增功能需要补充相应的原型和文档
- 保持文档与实际实现的一致性
